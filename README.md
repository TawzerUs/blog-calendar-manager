# Blog Calendar Manager

A comprehensive React application for managing blog content calendars, editorial planning, and content analytics.

## Features

- 📅 Interactive Calendar View
  - Monthly theme planning
  - Weekly content structure
  - Color-coded categories

- 📝 Content Management
  - Add and edit blog posts
  - Assign posts to specific weeks
  - Track content status
  - Content type categorization

- 📊 Analytics Dashboard
  - Content progress tracking
  - Monthly statistics
  - Completion rates
  - Visual progress indicators

- 🎨 Modern UI
  - Responsive design
  - Clean and intuitive interface
  - Accessibility features
  - Dark mode support

## Tech Stack

- React
- Tailwind CSS
- Lucide Icons
- ShadcnUI Components
- React Router
- Local Storage for data persistence

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/TawzerUs/blog-calendar-manager.git
cd blog-calendar-manager
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

```
src/
```
